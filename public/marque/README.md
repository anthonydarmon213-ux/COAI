# Visuels de marque COAI

Récupérés le 02/09/2026 d'un ancien clone du projet posé sur le Bureau, où
ils n'étaient pas versionnés : ils n'existaient qu'en un seul exemplaire, sur
une seule machine. Ils sont désormais sauvegardés avec le reste du dépôt.

Ces fichiers ne sont pas utilisés par le site. Ils servent aux réseaux
sociaux, aux publicités et aux supports externes.

## Ajouter un visuel
Dépose-le ici s'il sert à la communication externe. Pour un visuel affiché
par le site, utilise plutôt le dossier correspondant à son contenu :
`public/repas`, `public/exercices`, `public/programmes`, `public/recuperation`
ou `public/videos`.
